# 💊 Aplicativo de Lembrete de Remédios

## 📌 Objetivo

Este sistema tem como objetivo ajudar o usuário a organizar seus remédios e lembrar de tomá-los no horário certo.

O usuário cadastra o remédio apenas uma vez, informando o nome, horário e dose. O aplicativo repete automaticamente todos os dias, sem precisar cadastrar novamente.

O sistema envia alertas com som e vibração, funcionando como um despertador. O usuário pode marcar quando tomou o remédio ou adiar o aviso.

A tela do aplicativo é simples, com textos grandes e cores para facilitar:
- 🟢 Tomado  
- 🟡 Pendente  
- 🔴 Atrasado  

## 🎯 Objetivo principal

Ajudar o usuário a não esquecer de tomar seus remédios e manter uma rotina mais organizada e segura.
